# 贸大百事通助理

UIBE All-Knowing Assistant 是一个使用 Python、OpenAI 风格 SDK 和 Gradio 开发的本地校园助理，助理昵称为“贸小通”。它在实验二学院助理的基础上扩展校园知识目录与本地业务，提供连续问答、资料查阅、课表、教师、考试、表单文件和邮件提醒等功能。

## 功能

| 模块 | 主要能力 |
| --- | --- |
| 与贸小通对话 | 流式和非流式回答、多轮上下文、编辑重发与分支切换、按学号分类的本机历史 |
| 模型设置 | 选择服务商返回的可用模型；联网补充和深度思考分别开启 |
| 资料卡片 | 学习、生活、社团、健康福利、财务、职业、交通、信息技术和国际交流九类目录 |
| 来源查阅 | 回答中的来源编号关联原始资料、来源链接和适用范围 |
| 教师资料 | 按学院和专业或系所浏览、搜索，公开邮箱快捷填入邮件 |
| 课表查询 | 图片识别草稿校对、按周显示、课程调整、空闲时间安排事务、关联邮件提醒 |
| 考试安排 | 导入本人通知或考试总表，按学号与学期查询并设置提前提醒 |
| 文件管理 | 从申请表模板创建个人副本，预览、指定字段填写、下载、重命名和选择邮件附件 |
| 发送邮件 | 上传、拖拽或选择管理文件作为附件，预览确认后发送 |

九类目录不代表全部校园事实均已收录。知识资料为保留日期、版本和适用对象的本地快照，最终仍以对应官方通知为准。

## 安装

项目曾在 Windows、Python 3.14.4 环境验证。安装 Python 后，在 PowerShell 中运行：

```powershell
git clone https://github.com/CenMunn/UIBE-All-Knowing-Assistant.git
Set-Location UIBE-All-Knowing-Assistant
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

在 `.env` 中填写自己的 `DEEPSEEK_API_KEY`、`DEEPSEEK_API_BASE` 和可用的 `DEEPSEEK_MODEL`。Base URL 应为服务端基础地址，不要填写到 `/chat/completions` 路径。模型和接口能力可能变化，应按自己账户和服务商当前支持的参数配置。

网页入口：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\src\web_app.py
```

浏览器访问 **http://127.0.0.1:7861/**。保持终端运行；停止时按 **Ctrl+C**，正常停止显示“服务已停止”。再次运行只需进入项目目录执行启动命令。不要同时启动多份管理相同本地数据的程序。

命令行入口：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\src\assistant.py --help
```

命令行参数以帮助输出为准；网页的联网、模型目录和业务工作区不代表命令行均具有同样入口。

## 配置说明

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 自己的模型服务密钥 |
| `DEEPSEEK_API_BASE` | OpenAI 兼容的 API 基础地址 |
| `DEEPSEEK_MODEL` | 聊天模型名称 |
| `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURITY` | 可选的发信服务器、端口和传输方式 |
| `SMTP_USERNAME`、`SMTP_PASSWORD` | 可选的发信账号和密码或专用授权码 |
| `TIMETABLE_VISION_MODEL` | 课表识别使用的图像模型 |
| `TIMETABLE_VISION_ENDPOINT_CONFIRMED` | 自定义端点已经确认支持图像输入时的显式确认 |

未配置SMTP时可先体验问答、资料查阅和本地工具。模型调用和联网工具可能产生服务商用量。图片识别需要实际支持图像输入的模型，仅配置一个模型名称并不代表它具有识图能力；确认开关也不会改变服务商能力。

## 使用流程

1. 个人资料中按需填写专业、入学年份、年级与第一或第二学期，并决定是否允许个性化回答。
2. 输入问题，Enter发送，Shift+Enter换行；生成中避免重复提交。已发送问题可以编辑并切换版本。
3. 从资料卡片查阅政策和培养方案；引用编号可用于阅读依据。
4. 上传课表图片后核对星期、课程、教师、节次及周次，再保存；首次使用校准教学周，识别疑点需人工确认。
5. 需要申请表时，先在文件管理创建个人副本再填写；正式提交前核对导出文件。
6. 邮件和提醒在相应模块预览、确认后才执行；程序休眠、退出或断网可能影响提醒。

表单采用保留原表框架、在指定位置填写的方式，无需Docker或额外Office文档服务，不能当作任意Word排版编辑器。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `src/web_app.py` | 网页入口与事件绑定 |
| `src/assistant.py` | SDK、消息构造和命令行入口 |
| `src/conversation_*.py` | 本机历史与分支状态 |
| `src/document_*.py`、`src/form_*.py` | 文件、预览、模板填写与访问控制 |
| `src/timetable_*.py` | 课表识别、周次、排课及事务 |
| `src/exam_*.py` | 考试导入与查询 |
| `texts/prompts/` | 独立Prompt及其迭代版本 |
| `knowledge/` | 校园条目、专题解读、来源和模板目录 |
| `resources/` | 页面样式、交互脚本、公开资料、表单模板及分词资源 |
| `images/` | 校徽和聊天头像 |
| `.env.example` | 无真实凭据的配置模板 |

首次运行会按功能需要创建 `.private/`、`data/` 和相应数据库。保留这些目录才能继续访问本机聊天、个人文件、课表和提醒。

## 数据范围与使用限制

- 公开仓库未包含真实API密钥、邮箱凭据、学生考试总表、聊天日志、个人课表、个人文件和实验报告。考试功能需自行导入有权使用的数据。
- 当前校园精选目录包含86条资料。各条适用年份、对象与核对日期须分别阅读，旧学期的考试或课程资料不能代替当前个人安排。
- 联网搜索可能没有有效结果。系统应区分本地快照与本轮实际取得的联网摘录；不能把页面“报名中”标签或活动开始时间当成有效报名截止。
- 本机学号分类不是正式身份认证；文件及课表等工具也不构成完整多用户权限隔离，不建议直接公开暴露本地服务。
- 校徽、公开政策、培养方案和第三方资源的权利归原权利人，本仓库不另行授权其商标或内容。
